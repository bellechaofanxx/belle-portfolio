# Joanna Belle Betonio — Portfolio

A static portfolio site built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — responsive red editorial design
- `script.js` — portrait cursor motion, custom cursor, mobile menu, accordions and reveal animations
- `assets/belle-portrait.png` — hero portrait

## Run locally in VS Code
1. Open this folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also double-click `index.html`, but Live Server is better while editing.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files in this folder, keeping the `assets` folder intact.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your main branch and `/ (root)`, then save.

## Before publishing
Replace the placeholder LinkedIn URL in `index.html` with your actual LinkedIn profile URL.
